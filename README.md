# 三四

正式入口为 [《三四》江湖行旅](https://sansitemple.com/)。项目由人确定玩法、人物参考和验收标准，AI 按反馈实现与修订代码和素材，并执行测试。实物扫描和第三方贴图的来源另见游戏内署名。

在「行旅 → 行旅簿 → 主题游线」可找到三条串联现有活动的路线：一叶到一盏、人间烟火、山中听音。路线认可以往和乱序完成的学习记录，仅到访不算完成；点路线按钮先看下一站，再决定是否启程。

《三四》是一款可以结伴游览、学手艺和经营摊位的浏览器 3D 行旅游戏。首页可选中山装或学生裙游客，调整行速、画质和声音。默认快行，键盘按住 Shift 或将手机摇杆推到底可加速。

路上使用“四方钱”。读图、完成各地课业、给书铺送书或在柳巷拳馆对拍切磋，都能赚取随机报酬。茶摊、饭棚和客舍各有免费与付费选项。镇上可以租杂货摊、进货配货、添供果和雇车，柳巷拳馆可以求师。按 B 打开钱袋，传送门可回到已到访的地方。钱袋、摊位和课业随本机行旅进度保存。

默认从三四镇南门出发。沿长街过石桥，出北门走到驿道。直行穿过第一个岔口便到少林寺，正路旁的阿岚会提灯候客。面对她按 **E**（触屏点「同行」），她就从两尊石狮之间带路，穿过山门走到前院红香案。停步时她会回望等候；不想同行可以直接离开。请香仍须自己在案前完成，同行不会代做功课，也不会移动玩家或发放奖励。

当前本地版本可以往返嵩山少林寺、三四镇、武当、明教石灯院、丐帮河岸会所、峨眉、华山、昆仑、崆峒和平川镖局总号。按 **M** 或点底部「行旅」，看各驻地的步行方向，沿路碑自行前往。三四镇有客栈、临水茶棚、书铺、平川镖局驿站和丐帮歇脚处；可以过桥游街、坐下休息，在茶具前按 **E** 完成温杯、置茶、注水。

「三四行旅图」展示 20 个目的地。原山寺现为嵩山少林寺，重搭三券山门、重檐大雄宝殿和藏经阁，保留主佛、存档和多人房间。图中标有寺院、道观、作坊、镖局、集镇与水路驿站，二十处均可步行到达。驿道南侧的十条支路通往西域织市、石关驿、峡口山寨、双溪渡、柳巷拳馆、竹溪铁铺、芦湾水驿、盐湾集、海门船行和海岛远行。各处有本地人物、两步体验和歇脚座位，进度自动写入行旅簿。图上的地形、方位和路线是游戏安排，不对应实际地理距离。前院西侧六祖堂供达摩木雕，武当东廊可与张三丰交谈，峨眉清音学舍可辨认茶芽标本。

寺观建筑和供像参考现实文化，人物对白、院落游线与各地日常由《三四》编排。少林大雄宝殿供三佛，东有紧那罗殿、西有六祖堂，后山松径可坐禅。武当紫霄殿奉真武，东廊可通演式庭与三清殿。镇上街坊在平川镖局驿站旁的财神殿供奉赵公明。峨眉普贤殿供骑白象的普贤菩萨，清音学舍可看茶芽标本。华山山下希夷祠奉陈抟，山上议事堂可向巡山师兄问路。崆峒皇城与拳院分路，昆仑松雪谷的听雪客堂接待来客。石灯院两侧开有作坊，丐帮南埠可见分粥和收货。

地图可拖动、缩放，键盘方向键可在目的地间选择；**M / Esc** 收图，图内 **1–9** 依次查看少林寺、三四镇、武当、明教、丐帮、峨眉、华山、昆仑、崆峒，**0** 查看平川镖局。「行旅簿」读取本机真实游历与学习记录，目的地详情提示未完成学茶、巡识、帮厨、采青或听弦的下一步。看图时暂停场景绘制和角色输入，多人连接继续接收状态；收图后在原处继续走。

武当可从松间古道登上太极坪，在紫霄殿看真武，到后院父母殿和西侧藏书阁参观，到听松亭、听风台静坐。太极坪按 **E** 开始云手练习，跟随道人完成起势、云手、收势；手机用「随式」按钮，随时可收势离开。刷新后可选「继续上次行旅」恢复最近地区与位置，学茶和云手记录保存在原存档的 `journey` 字段。

明教石灯院有砂岩关隘、石灯广场、作坊、西望台和可走通的后山石道。五处器物分别演示编钟、木构、水车、风箱和山形层叠；观察齐全后回到巡识桌记录。石灯院的建筑、作坊与器物演示均为游戏设计。演示和学习记录属于当前访客，暂不广播共享机关状态。

丐帮河岸会所是为游戏设计的独立驻地：老街、修补摊、树下聚会处、客舍、开敞会所、饭棚和木码头。饭棚可依次提桶添水、量米下锅、执勺慢搅、分粥待客；完成后记录「围炉帮厨」。中途离开或地区被回收，返回可以继续。原镇中歇脚处保留，并增加前往会所的路牌。

峨眉有竹影山径、三行茶圃、清音学舍、听雨亭和较高的望云台。茶圃可辨认嫩芽与老叶，采下三处不同嫩梢，再到茶屋摊入竹匾，完成「采青识叶」；嫩梢、篮子与竹匾随操作变化。中途离开、场景回收和刷新都保留进度，重复采同一枝不会增加数量，完成只记一次。此活动仅表现采青与摊叶，不模拟完整制茶工艺；基本叶色与采摘知识参考 [Horniman Museum and Gardens](https://www.horniman.ac.uk/story/all-about-tea-camellia-sinensis/)。山路与驻地布局是游戏创作，并非真实景区复刻。

华山是一条连续登高路线：山门石阶通剑坪，东侧沿崖上行、过木桥到歇脚亭，再登朝阳台。可以在听剑舍、茶亭和峰顶静坐。在剑坪按 **E**，随教习完成提剑、平刺、收剑；手持木剑随肩肘动作移动，完成后记录「木剑三式」，取消不会获记。手机可轻触「随式」与「收剑离开」。动作与驻地是三四的创作，不作为真实门派招式或景区路线的复刻。

从石灯院下山沿驿道向西，到昆仑路碑转向北。雪道通向听雪琴院，西侧有茶亭，东侧可绕静池登望雪台。琴案前按 **E** 开始听弦：数字 **1–7** 或触屏按钮拨动七根弦，先听一、四、七弦的低、中、高音，再随一、四、七、四的短句。示范会同步发声与点亮弦位，示范本身不计完成；没有限时，随时可离开。琴弦在场景中振动，声音经现有音效总线播放，背景音乐在听弦时减弱。学习中断、场景回收与刷新保留进度，完成只记一次。琴院、音色和短句为游戏创作，不宣称复现真实古琴曲谱或门派演奏法。琴声与琴弦操作目前属于本机体验，访客位置仍按地区同步。

从华山下山沿驿道向西，下一个北向岔路通往崆峒。山门入拳坪，西阶通观山窟，沿洞外石道上古道驿亭，再从东阶回到拳坪，形成可连续走完的一圈；石窟与驿亭均有坐席。`world/grotto.js` 构造真实开口、连续弧顶与凹凸岩壁，周围岩体留出洞外通路。拳坪按 **E** 跟随教习守式、出拳、收势，手机使用「随式」按钮；肩肘和腰身共同转动，两手增加随关节运动的布裹握拳外观。取消不获学习记录，完成后记入「空拳三式」。本人、教习及远端访客使用相同动作函数，动作结束隐藏布裹拳套；更换外观或访客离开时释放其资源。动作、驻地与山路是游戏编排，不声称复现真实门派技法。

拳坪的中央练习区与各出口由石板步道连接，边缘保留土石和低矮草木。`world/court-garden.js` 将石板合为单个网格，沿用已有石材扫描的颜色、法线和粗糙度；以独立 UV 采样石面，避免在新接缝中叠出旧贴图的格缝。材质副本随异步贴图更新，不改公共材质。草叶采用有弯曲的实体薄片，按位置分组实例化以便视锥裁剪；小花和两棵近松丰富路边层次。松旁长凳有两个朝向教习的可坐位置，按 E 或触屏互动按钮坐下。新增细节增加部分机位的几何和绘制调用，真实手机开销仍待验证。

平川镖局总号位于驿道东端，从平川路碑转向北。签押房有两张运单，东岸茶庄的瓷盏需要草衬和渡船，西门书铺的书册需要油布和路车。正确交付第一件货后记入「西车东渡」，两件货及在途进度保存在本机。临河茶棚有两个休息座位。

芦湾水驿、西域织市和其他帮会仍属于世界规划，尚未全部建成。各地多人功能通过本地 Worker 按地区隔离；尚未发布本轮改动，也未验证公网跨设备联机或真实移动设备性能。

## 打开方式

通过静态 HTTP 服务打开 `index.html`，例如 `python3 -m http.server 8854`。本地 ES 模块需要 HTTP 服务；线上发布需同时包含 `world/`、`characters/` 目录和对应的 Worker。

新增地区沿用同一个渲染器、材质、建筑与人物构造器。地区各自保存场景组、碰撞、寻路、NPC 和互动点，仅绘制当前场景。`world/regions.js` 处理加载、缓存与失败恢复，`world/adapter.js` 连接既有游戏系统，`world/town.js`、`world/wudang.js`、`world/ming.js`、`world/beggar.js`、`world/emei.js`、`world/huashan.js`、`world/kunlun.js`、`world/kongtong.js` 构建地区，`world/practice.js` 管理云手、木剑与空拳练习，`world/sword.js` 管理木剑道具及姿态，`world/fist.js` 管理布裹握拳外观及空拳姿态，`world/meal.js` 管理帮厨进度，`world/tea-garden.js` 管理采青记录；`world/qin-lesson.js` 管理听弦进度，`world/qin.js` 管理键盘和触屏面板，`world/qin-audio.js` 合成有衰减的拨弦音色。服务端用 `r=town`、`r=wudang`、`r=ming`、`r=beggar`、`r=emei`、`r=huashan`、`r=kunlun`、`r=kongtong` 隔离各地访客，原寺院房间保持兼容。

少林寺与驿道常驻。接近路口时加载可见的驻地，离开后回收超出缓存的驻地。`world/resources.js` 释放该地区的几何体、材质、贴图、骨骼和阴影资源，并保留其他场景、公共构造器及访客仍在使用的资源。步行重访时从所在的山门进入，保留学茶步骤和百工访学；这些轻量状态随原存档保存。回收后的重访需要重新生成建筑与人物，切换耗时仍需在真实手机上验证。

峨眉、武当和明教的院外山景由 `world/landscape-field.js` 与 `world/landscape.js` 构建：确定性的山脊、沟谷和林地，按块裁剪的山体网格，复用既有岩石扫描贴图的三向投影材质，以及分组实例化的远景树冠。树根落在实际三角形地表上，分块边界共享高度和法线。景观位于原有栏杆之外，不增加步行区域或碰撞；主寺和近景建筑保持原样。增加森林会增加部分机位的绘制量，分块也会增加绘制调用，不能把可见三角形减少等同于帧率提升。

华山使用同一山景构造器，采用 4 米网格和独立峰脊参数。`world/granite.js` 为近处岩壁与远山提供同尺度的花岗岩材质：复用既有扫描贴图，以两种尺度的三向采样降低重复，叠加缓慢变化的色泽与细部凹凸。台基下方的岩壁、外扩山脚与岩柱使用独立几何体，顶部贴合原台基；岩柱避开三段石阶的通行范围。它们不参与步行碰撞。此细化增加了华山的三角形和着色开销，真实手机性能仍需验收。共享扫描贴图由原场景持有，华山回收时只释放自己的材质与几何体。

华山七棵近景松树由 `world/pine.js` 构建，位置与树干碰撞延续原布局。主干、分枝和细枝共用连续曲线取样，针叶簇按树分组实例化，树冠从侧面和下方也有厚度。`world/pine-needles.js` 生成细针叶纹理与保持透明覆盖率的缩小层级，替代近景中的密集扇形笔划；树皮继续引用已有扫描材质。针叶使用漫反射光照，颜色与阴影共用微风形变。区域回收同时释放自定义阴影材质、实例缓冲和本地区针叶贴图，保留公共树皮扫描。昆仑和崆峒也复用这套近景松树，原寺院与其余地区的松树构造器保留。

多人状态保留原有的位置、朝向与三项姿态，增加可选的云手、木剑或空拳练习阶段和进度。`world/presence.js` 为前端和 Worker 共用校验；远端动作最多推演 600 毫秒，网络停滞后停在最后姿态。访客进入时接收最近状态快照，取消或暂歇会清除练习动作，学习记录只写到练习者自己的存档。远端复用本人的人物构造器和已选外观；改名或更换外观会重新广播身份。

`characters/motion.js` 在既有人物上加入髋、膝、踝联动与落脚保持，衣摆按步态和坐姿插值。上半身仍使用原有的合十、礼拜与练武关节控制。人物更换和远端访客离开时释放各自的几何体与骨骼资源。

运行人物动作、地区切换与房间路由测试：`node --test tests/*.test.mjs`。

## 说明

- 游戏以建筑模型、角色动画、原创造像和声音营造可步行的江湖，场地布局经过创作。
- 山中香客为电脑控制的角色，并非其他真实玩家。
- 进度（香火、礼拜、念珠、功德、静坐时间）保存在本机浏览器中。
- 三维引擎优先加载本地 `three.module.min.js`；失败后依次尝试 jsDelivr、npmmirror、unpkg、cdnjs 的固定 r160 版本。

## 茶棚回归检查

从项目根目录运行 `python3 -m http.server 8000 --bind 127.0.0.1`。在装有 Chrome、Node.js 且能加载 `playwright-core` 的环境中，另开终端运行 `node tests/browser/town-tea.cjs`（可用 `GAME_URL` 指定其他服务地址）。测试从「进入三四镇」进入，用方向操作走到茶桌，按 E 完成三步，再检查行旅簿、下一站和刷新后的记录。

`node tests/browser/gate-walk.cjs` 检查提灯客沿途的寻路地面和障碍净空，用电脑操作走通山门到香案，并以模拟触屏确认英文「Follow」可以发起同行。

同一环境可运行 `node tests/browser/surface-colors.cjs`。它分别以桌面和模拟触屏打开游戏，检查七个材质应用成功，并逐像素对照浏览器解码的原图调色结果。请从含原始 JPG 的本地项目运行，而非发布站点。离线调色替代了入场时的五次像素读回、遍历与写回。本地 Chrome 测得六张颜色图的响应正文合计由桌面 4,761,275 降至 3,232,594 字节，触屏 569,589 降至 547,240 字节；不包含其他资源，也不是首帧耗时或真机帧率。
