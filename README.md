# huasi

华山寺 · 山寺 · 上香 · 静坐 —— 一座在浏览器里打开的 3D 山中寺院。

无需安装、无需注册，打开网页即可：

- 请香、点香、炉前三拜敬香；蒲团静坐、随呼吸调息；礼拜计数至一百零八
- 拨念珠、敲木鱼、与山中香客合十问讯
- 祖师殿求签（一日一签）、观音殿供灯、藏经阁阅经、祈福架挂祈福牌、绕塔三匝
- 东院财神院：财神殿拜财神、请今日福袋、聚宝池投福币、摸金元宝、钻钱眼、摸福字；月老祠系红绳
- 西院文昌院：文昌阁祈学业、走状元桥、禅茶寮饮茶
- 钟楼、鼓楼可沿楼梯登顶撞钟击鼓；镇岳塔可入塔登上凌云台远眺
- 每日功课与连续天数、朝山印记（十八处）、拍照留念、观云台放天灯、放生池喂锦鲤
- 中文 / English 双语，首页右上角切换；古琴与箫的生成式背景音乐
- 放生池看锦鲤、花树落英、逗逗寺猫；晨、午、暮、夜四时可换
- 手机上轻点地面即可前往

## 打开方式

直接打开 `index.html`，或通过 GitHub Pages 访问本仓库的网址。

## 操作

| 电脑 | 手机 |
|---|---|
| W A S D 行走 · 鼠标环顾 | 轻点地面前往 · 拖动环顾 · 左下摇杆 |
| E / 左键 互动 | 右下圆钮 互动 |
| 1 礼拜 · 2 念珠 · 3 木鱼 · 4 合十 | 底部圆钮 |
| V 视角 · T 时辰 · H 隐藏界面 · Esc 暂停 | 右上「时辰」「暂歇」 |

## 说明

- 场景、人物、音效均由代码生成，为艺术再现，并非任何真实寺院或官方服务。
- 山中香客为电脑控制的角色，并非其他真实玩家。
- 进度（香火、礼拜、念珠、功德、静坐时间）保存在本机浏览器中。
- 三维引擎 three.js 依次尝试从 jsDelivr、npmmirror、unpkg、cdnjs 加载；也可将 `three.module.js` 放在本目录下自行托管。
