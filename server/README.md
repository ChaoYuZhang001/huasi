# 附近的人 · 多人同房服务端

网页和中转是**同一个 Cloudflare Worker**（名字 `huasi`）：网站文件由静态资源层直接返回，只有 `/ws`、`/health` 和 `/api/xiang` 会运行 `server/worker.js`。配置在仓库根目录的 `wrangler.jsonc`。

`.assetsignore` 决定哪些文件**不**作为网站公开：`server/`、`art/`、配置文件和说明文档都不对外提供。

## 部署

- **自动**：Cloudflare 控制台里的 Workers Builds 已连接本仓库（根目录 `/`，部署命令 `npx wrangler deploy`），推送到 `main` 后由 Cloudflare 构建并发布。如果推送后线上没有更新（2026-11-15 夜间出现过，原因未查明），用下面的手动方式。
- **手动**：

  ```bash
  CLOUDFLARE_API_TOKEN=<token> sh server/deploy.sh
  ```

  脚本先导出一份已提交内容的干净副本，再发布这份副本。Token 在控制台「My Profile → API Tokens → Create Token」用「Edit Cloudflare Workers」模板创建；脚本只从环境变量读取，不保存也不打印。这条路只访问 `api.cloudflare.com`，在打不开 `dash.cloudflare.com` 登录页（`wrangler login` 会超时）的网络下也能用。

**不要在仓库目录里直接运行 `wrangler deploy`。** 它发布的是工作区当前的全部文件：未提交的改动、草稿页面、日志文件都会变成公开网址。

发布后可以这样确认：

```bash
curl -s https://sansitemple.com/health
```

返回 `ok` 说明中转在运行。

## 它做什么

- 距离 3 公里以内的访客互相可见：能看到对方的名字、位置和动作（行走、礼拜、合十、静坐）。没有聊天，没有账号。
- 位置来源有两种：
  - **默认**：按访客 IP 定位。这是城市级精度，通常偏差几公里到几十公里，**做不到 3 公里**。同一城市的访客往往被定位到同一个点，于是互相可见，界面显示为「同城 · N 人」。
  - **精确**：访客在菜单里点「附近的人」并同意浏览器的定位请求后，用真实坐标匹配，界面显示为「附近 3km · N 人」。只有双方都授权时，3 公里才是准的。
- 坐标只在服务端用来判断谁离谁近：取整到约 100 米，只存在内存里，连接断开即丢弃，不写入存储，也不会发给其他访客。对方只收到一个临时编号、名字、外观编号和动作。
- **全山在线**：连上后 6 秒内附近没有人，页面改连共享房间 `/ws?c=world`，界面显示「全山 · N 人在线」。这个房间不收任何坐标，里面的人彼此都可见（上限 120 人）。附近有人的访客留在本地房间，不进共享房间。
- **今日全山香火**：`GET /api/xiang` 返回 `{d, n}`（中国日期、当天总数）；敬完一炷香时页面 `POST` 一次，横幅显示「今日全山第 N 炷」。数存在名为 `stats` 的 Durable Object 里，一天一个键。同一 IP 每 15 秒最多计 1 次、每天最多 60 次；这个限速表只在内存里，不落盘。POST 必须带允许的 `Origin`。
- 真人头顶的名牌是玉绿色、前面带「●」，和脚本里的香客（白色名牌）区分开。
- 山寺、三四镇、武当、明教、丐帮分别连接 `r=temple`（可省略）、`r=town`、`r=wudang`、`r=ming`、`r=beggar`；同一位置匹配规则只作用于同一区域。旅行时关闭旧连接并重新加入目的地区域。作坊器物演示、围炉帮厨和学习进度仍属于各自客户端，暂不广播共享机关或共用锅具的状态。
- 武当云手在原有 `a:[静坐,礼拜,合十]` 之外增加可选 `x:[1,阶段,进度]`。阶段为 0–2，进度为 0（含）到 1（不含），非法或缺失的扩展按未练习处理。旧客户端仍可同步原动作。发布时前端和 Worker 应一起更新；旧 Worker 不会转发云手字段。
- 握手增加已选人物外观 `g`（仅接受 `f` / `m`），随身份消息发给其他访客；两端共用同一人物构造器。缺少该字段的旧客户端沿用种子外观。改名/改外观会重新连接以更新身份，并移除旧人物。
- 入场者会在身份消息后收到其他访客最近 20 秒内的姿态快照；快照保存在 WebSocket attachment，未写入数据库，不含地理位置。关闭/错误事件只通告离开一次，并明确回送关闭帧，避免浏览器卡在关闭状态而无法重连。

## 地址与来源限制

- 网站：`https://sansitemple.com`、`https://www.sansitemple.com`、`https://huasi.<账号子域>.workers.dev`；中转是各自地址下的 `/ws`。
- 自定义域名在 `wrangler.jsonc` 的 `routes` 里声明，部署时自动创建解析记录和证书。声明自定义域名后 `workers.dev` 默认会被关闭，所以配置里显式写了 `"workers_dev": true`。
- 页面从上述任一地址打开时自动连接同一地址的中转，不需要配置。GitHub Pages 副本（`chaoyuzhang001.github.io/huasi`）会跨域连接到 `workers.dev` 上的中转。副本从 Git 跟踪文件中按根目录的 `.assetsignore` 筛选发布内容，首页标记为 `noindex`，分享链接与规范网址均指向主站。玩家可在原域名继续本机存档。
- `wrangler.jsonc` 的 `ALLOWED_ORIGINS` 列出允许跨域连接的网址；同源永远允许，没有 `Origin` 头的连接会被拒绝。

## 本地测试

不需要 Cloudflare 账号。`dev_server.py` 是协议相同的本地替身，自带三个会走动的香客，也应答 `?c=world` 和内存版的 `/api/xiang`：

```bash
python3 server/dev_server.py
```

然后打开 `http://localhost:8848/index.html?mp=ws://127.0.0.1:8849`（`?mp=` 参数只在 localhost 下生效）。

要在本地运行真正的 Worker（网站 + 中转），在仓库根目录执行 `npx wrangler dev`。

本轮使用 Wrangler 4.162.0 的 **local** 模式运行真正的 `server/worker.js` 和本地 Durable Objects，再让两个独立 Chrome 上下文通过 WebSocket 连接。三地相遇/离开、行走和合十、云手三个阶段、完成/取消/暂停、断线重连及关闭窗口均已验证。协议检查还覆盖旧客户端、异常动作、越界坐标、来源限制和就近房间隔离。证据保存在仓库外 `research/sansi-multiplayer-runtime-20261118/`；它不是公网或真机验收。上面的 Python 替身未用于此次验证，也未同步升级云手和分区协议。

## 用量与限制

观云台的天灯是一次性事件，不加入进房快照，不写入数据库。只转发放灯者的临时连接 ID、游戏场景内的释放位置和风向种子，不传心愿或个人计数。真实 Worker 只接受少林寺房间内、最近十秒的位置与灯场相符的访客放灯，每连接两次至少间隔 2.5 秒，仍按原有附近范围筛选收件人，不回发给本人。旧客户端不认识该事件时仍可正常游览。

运行真实本地 Worker 与静态页面后，可用 `GAME_URL` 和 `RELAY_URL` 指定两个地址，运行 `node tests/browser/shared-lantern.cjs`（Chrome 与 Playwright Core）。默认页面为 127.0.0.1 的 8854 端口，中继为 8856 端口的全山房间；若两个端口不同，须在本地 Worker 允许页面来源。测试从三个独立浏览器存档恢复到灯场，不验证从山门步行到灯场的路线或公网联机。

- 免费版 Durable Object 每天 10 万次请求，WebSocket 消息按 20 条算 1 次。页面走动时每秒发 4 条位置（全山房间 2.5 条），站着不动每 8 秒发 1 条心跳；对方 20 秒收不到消息才把人移除，再收到时自动重新显示。粗略估算，持续走动时全站一天合计约 140 小时在线才会用完；超出后新连接失败，页面自动退回单机。香火计数每次敬香 1 次请求，另外每人每 5 分钟读 1 次。
- 第一人称视角下也发送真实位置和动作（之前第一人称时别人看到的是静止不动的人）。
- 中转逻辑已在线上用真实连接实测（2026-11-16）：握手与来源限制、3 公里匹配、名字清洗、限速、越界位置丢弃、离开通知、坐标不外泄、按 IP 定位的分支。多台真机同时在线尚未测过。
- `workers.dev` 在中国大陆连通性不稳定；连不上时页面自动退回单机，界面上不显示「附近」计数。自定义域名通常更稳，但尚未在大陆网络下实测。
- 按 0.5 度（约 55 公里）划分房间。恰好分处两个格子边界两侧的近邻互相看不到。
- 每个房间上限 400 人，客户端最多同时显示 24 人。
## 峨眉地区

本地新增 `r=emei`，与寺院及其他驻地分房。地图与三四镇实体路牌均可前往；采青与摊叶只记在各访客本机存档，不广播共享采摘状态。此项已用两个独立浏览器上下文连接本地 Worker 验证，尚未发布或验收公网跨设备联机。

## 华山与木剑动作

新增 `r=huashan`，同样隔离世界与就近房间。原可选 `x` 动作扩展增加木剑类型 `x:[2,阶段,进度]`；类型 1 仍为云手，两者均有 0–2 三阶段，进度范围 `[0,1)`。缺失或非法值清除当前练习动作。初次加入可收到正在练习者的快照，客户端最多推演 600 毫秒；动作结束隐藏木剑，学习记录仍只保存到练习者本机。

本地两个独立 Chrome 上下文已验证：手机触屏模拟操作三式、另一访客中途加入看到持剑动作、结束清除、外观更换释放道具、地区隔离及回收重访。前端与 Worker 必须一起更新；不支持类型 2 的旧 Worker 会把木剑动作视为无效。本轮尚未发布至公网。

## 昆仑地区

新增 `r=kunlun`，与其他地区隔离。琴课的拨弦、示范声音和学习进度属于各客户端，不发送音频或共享琴弦状态；其他访客继续接收位置与朝向。前端与 Worker 的地区名单需同时更新。

## 崆峒地区与空拳动作

新增 `r=kongtong`，与其他地区分房。可选动作字段新增 `x:[3,阶段,进度]`，三阶段为守式、出拳、收势；仍采用相同的有限值校验、600 毫秒推演上限、到达快照和结束清除机制。云手类型 1、木剑类型 2 保留。前端与 Worker 的动作类型和地区名单须同时更新，旧 Worker 会把类型 3 当作无效动作。学习记录仍只写到完成者本机。
